# 🛡️ CadetConnect — NCC & Defence Aspirant Professional Community Platform

**CadetConnect** is India's dedicated professional ecosystem and digital network built specifically for **National Cadet Corps (NCC) Cadets**, **Armed Forces Aspirants**, **SSB Mentors**, and **Military Veterans**.

---

## 🌟 Key Features

- **🪖 Digital Cadet ID & Journey Timeline**: Log ranks (Cadet to SUO), CATC/TSC/RDC camp achievements, and verified regimental records.
- **🔐 Regimental Privacy Vault**: Full NCC Regimental Numbers are encrypted and strictly protected from public display.
- **📚 Centralized Defence Knowledge Hub**: Access verified weapon manuals (.22 Deluxe, 7.62mm SLR, INSAS), drill commands, map reading formulas, and SSB OIR/TAT/WAT practice sets.
- **📄 Working Document Upload & Download**: Upload PDF notes and study materials with real browser download integration.
- **🤝 1-on-1 SSB Mentorship**: Book personal interview sessions with recommended candidates and veteran officers.
- **🤖 Veer AI Assistant**: Integrated 24/7 AI tutor for NCC syllabus, weapon specs, and defence exam strategies.
- **🔐 Multi-Method Authentication**: Sign in via **Google OAuth**, **Mobile Number OTP**, or **Email/Password**.

---

## 🛠️ Technology Stack

- **Frontend**: React (Vite), TailwindCSS, Lucide Icons, React Router DOM
- **Backend**: Node.js, Express, WebSocket Server (`ws`)
- **Database**: LowDB JSON Database Engine with seed data

---

## 🚀 Quick Start (Local Setup)

### 1. Clone Repository
```bash
git clone https://github.com/stutiisfr/cadetconnect.git
cd cadetconnect
```

### 2. Install & Start Backend
```bash
cd backend
npm install
npm run dev
```
*Backend runs on `http://localhost:5000`*

### 3. Install & Start Frontend
```bash
cd ../frontend
npm install
npm run dev
```
*Frontend runs on `http://localhost:5173`*
